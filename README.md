# XDownloader — Загрузчик видео, фото и GIF из X (Twitter) для Android

Современное нативное Android-приложение для скачивания медиафайлов из социальной сети **X (Twitter)** с поддержкой выбора формата и сохранением видео в виде анимированных **GIF**.

---

## 🌟 Возможности приложения

1. **Скачивание всех типов медиа**:
   - 🎬 **Видео** (MP4 в качествах 1080p Full HD, 720p HD, 480p, 360p)
   - 🖼️ **Фотографии** (в оригинальном максимальном разрешении)
   - 🎞️ **GIF-анимация** (конвертация любого видео или сохранение оригинальных зацикленных анимаций X в чистый формат `.gif`)
2. **Выбор формата перед скачиванием**:
   - Перед загрузкой отображаются доступные разрешения, битрейт и кнопка выбора формата GIF.
3. **Встроенный GIF-конвертер**:
   - Преобразует видеопоток в полноценный `.gif` файл без водяных знаков и ограничений.
   - Частота кадров берётся из самого ролика (30 fps остаётся 30 fps), длительность GIF совпадает с исходником. Для 60 fps кадры прореживаются вдвое — GIF не умеет проигрывать быстрее 50 кадров/с.
   - Палитра собирается по кадрам, разнесённым по всему ролику, поэтому GIF не темнеет, если ролик начинается с чёрного кадра или с появления из темноты.
4. **Папка «Мои загрузки»**:
   - Все файлы (видео, фото, GIF) сохраняются в одну публичную папку **`Movies/XDownloader`** — она видна и в системной галерее, и в Проводнике.
   - Встроенная галерея внутри приложения: сетка превью, размер файла, бейдж формата, кнопка действий «Поделиться / Удалить».
5. **Удобная вставка**:
   - Кнопка «Вставить» из буфера обмена.
   - Поддержка системного меню «Поделиться» из официального приложения X.
6. **Поддержка разработчика**:
   - Встроенная кнопка и диалог для добровольных пожертвований через [CloudTips](https://pay.cloudtips.ru/p/9206d8ca).

## 🚀 Как собрать APK через GitHub Actions

В проект уже встроен готовый и проверенный workflow `.github/workflows/build_apk.yml` с поддержкой `gradle/actions/setup-gradle@v4`.

1. Создайте новый репозиторий на [GitHub](https://github.com/new) (например, `XDownloader`).
2. Распакуйте архив `XDownloader_Project.zip` и загрузите файлы проекта в корень репозитория (или загрузите проект через `git push`).
3. Перейдите во вкладку **Actions** в репозитории на GitHub.
4. Сборка **Build Android APK** запустится автоматически и через 1–2 минуты создаст готовый установочный `.apk` файл.
5. Скачайте файл из блока **Artifacts** (`XDownloader-debug-apk`) и установите на телефон!
